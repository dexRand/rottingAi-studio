# Add-on: Humanize

## Rhythm
Vary sentence length: mix short, punchy sentences with longer ones that carry
the detail. Break the uniform, mechanical cadence of generated text; never a
flat, list-like rhythm from start to finish.

## Cut filler
Remove hedging and throat-clearing: "I think", "it seems", "one could say",
"it is important to note that", "in conclusion", "as previously mentioned",
"credo che", "è importante notare che". Say the thing directly and stop.

## Concrete
Prefer specific nouns and verbs over vague abstractions. Show the detail
instead of hedging around it; drop empty intensifiers and stacked adjectives.

## Keep facts
Keep every fact, number, unit, date, name and quote UNCHANGED: never invent,
drop or paraphrase one. Rewrite only wording, order and flow, never the
substance.

## Language and output
Work in Italian and English; match the input language. Output only the
rewritten text: no preamble, no "Here is a more human version", no notes or
meta commentary.

- IT "È importante notare che il server è andato giù" -> "Il server è andato giù".
- EN "I think we should probably run the tests first" -> "Run the tests first".
